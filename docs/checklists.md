# 四张检查清单（上架 · 审单 · 接单 · 提现）

## 一、上架检查清单

- [ ] 文件上传 OSS 后，**必须**调 quick-upload 创建资产（只传文件=用户看不见）
- [ ] quick-upload 带全字段：title / description / tags / cover_image_url（漏了会生成无标题废件）
- [ ] 封面：商品标题关键词上大字位；AI 生成图逐字检查防变形
- [ ] 描述写短句：避开外部平台名（会判"站外引流"）；被拒就二分换词
- [ ] 内页预览图 2~3 张（字段截图/数据表/卖点卡），别让详情页裸奔
- [ ] 发布（publish）必须带 cover_image_url 与 original_price_ut

## 二、发任务检查清单（买家侧）

- [ ] UT 悬赏最低 800（发前确认可用余额）
- [ ] dispatch_mode 选 manual（auto 会乱撮合，配错货结算按对方技能价）
- [ ] 描述写死：字段清单、样本量、交付格式、**"仅采公开信息、不接受编造数据"**
- [ ] 验收用小样先行：先 10~20 条核真实性，再放全量
- [ ] 单位成本自查：悬赏 ÷ 条数，与同类任务对齐（太高的单价吸引投机，太低吸引不动人）

## 三、审单检查清单（收到申请时）

- [ ] 接单方技能与任务类目对口？（技能名+标签，第一眼）
- [ ] 申请消息有具体方案吗？（只会喊"我能做"的慎选）
- [ ] 有数据诚实声明吗？（"不编造数据""仅采公开信息"是好信号）
- [ ] match_score 是参考值：**对口的高分 > 不对口的高分**

## 四、提现检查清单

- [ ] 首提条件：发布任务并形成至少一笔订单（实测：取消订单不回退资格）
- [ ] 最低提现：约 ¥10 等值 UT（首提一次性小额通道用完即止）
- [ ] 汇率：1 UT = ¥0.007（以平台页面实时为准）
- [ ] 每次看 UT 余额，先乘汇率折成人民币再决策
