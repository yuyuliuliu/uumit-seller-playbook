# 踩坑实录（2026-09，持续更新）

每条都有当天操作与结果佐证。

## 1. auto 撮合会配错货

发任务默认 `dispatch_mode=auto`，平台把"餐饮数据采集"任务配给了"表格性能优化方案"技能，结算价按对方技能标价（51 UT）而非悬赏（800）。

**解法**：发任务选 manual；若被强制 auto（同账号已有 open 的 manual 任务），盯紧撮合结果，不对口立即取消——**实测取消后悬赏全额秒退，且首提资格不回退**。

## 2. 审核敏感词误判

- 描述含外部平台名 → 拒（"疑似站外引流"），换"本地生活平台"类通用词即过
- 某些正常词组合 → "低俗"误判；**解法：短句化 + 二分排查换词**

## 3. 封面质量评估 task_failed ≠ 图被拒

评估服务不稳时连报 4710/4714。**解法：换格式（PNG→JPEG）+ 缩尺寸 + PATCH media 重新触发**，实测一次通过。

## 4. 标题漏传 = 空壳废件

quick-upload 不传 title/description 会生成无标题资产，且**无删除端点**。重建时把元数据一次带全。

## 5. 官方钩子任务

大额 open 任务的发布者可能是平台官方账号（publisher = 系统保留 ID 如 `00000000-…-0001`）。申请这类任务大概率石沉大海——**投申请前先查发布者身份**。大厅还有 UT 归集噪音任务（"指定技能下单：xxx"、需求说明只写"1"），一律跳过。

## 6. 对口技能决定接单命中率

同一批任务：用一个"万能"技能申请，匹配分全 0.42；拆成专项技能线（各自对口标签）后重申，0.62~0.73。**平台和买家都用"技能-任务匹配度"判断你专不专业。**

## 7. 结算价规律

- auto 撮合：按被撮合技能的标价结算
- 人工接受申请：按任务悬赏结算

## 8. 加码比等待有效

30 条无人问津的任务，加码到 100 条（悬赏不变、放宽选样标准）后，申请从 0 涨到 32 份。"肥活好下口"——卖方视角重新包装你的需求。
