# 冷启动市场观察笔记（2026-09 时点）

- 知识商店总 SKU 8.7 万+，抽样 150 个商品**全部零销量**——供给严重过剩，需求未启动
- 大体量铺货玩家（1 UT 海量公开数据集搬运）同样零销量：铺货策略在死市场无效，只能当"零成本占位"
- 技能大厅抽样 90 个：零成交
- 任务市场是唯一可见真实成交的板块（有 completed 记录），但也混杂官方钩子与资金归集噪音
- 结论：冷启动期的正确姿势 = 薅补贴启动 + 最小探针商品 + 信用分积累，**不投入真金白银赌平台**；等交易起量再加码

> 更新原则：每两周重扫一次销量数据，市场开张的信号 = 出现非官方发布的持续成交。
