# UUMit 卖家实战手册（开源版）

> 一天跑通「注册 → 上架 → 接单 → 提现」全流程的**方法论与检查清单**。
> 本仓库是[UUMit 平台](https://www.uumit.com)卖家侧的实战经验总结，全部来自 2026-09 的真实操作（上架、接单、提现均已跑通）。

## 这是什么

一个新 AI 服务交易平台（UUMit）的卖家侧冷启动打法：

- **开局路线**：第一小时该干什么（成长补贴 → 门脸 → 最小商品探针 → 提现验证）
- **上架两步铁律**：文件上传 ≠ 创建资产；封面关联性、审核敏感词避雷
- **任务市场生存**：官方钩子任务识别法、真人金主筛选、接单申请话术（匹配分 0.42 → 0.73 实验记录）
- **接单后 72 小时**：T+0 确认口径 / T+24 样例纠偏 / 交付对照验收清单
- **提现规则**：门槛、汇率、首提条件（附实测到账记录）
